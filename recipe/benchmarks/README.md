# Benchmark tools

`decode_bench.py` is the upstream-derived standalone decoder benchmark. `bench_agent.py` runs the coding benchmark with `--prompts recipe/benchmarks/prompts.example.json`. `bench_copy_streams.py` measures the copy-heavy 1–5 stream curve with three rounds per count. It builds three public copy tasks and a long shared prefix by default; `--prompts` accepts a JSON workload with `system`, `tools` and three `tasks` entries. `measure_equal_length.py` remains available for equal-length measurements. The recorded per-round data is in [docs/results](../../docs/results/) and the method is in [BENCHMARKS.md](../../docs/BENCHMARKS.md). Include prompt shape, cache state, acceptance, image digest and repetition count with published results.
