# Benchmark tools

`decode_bench.py` is the upstream-derived standalone decoder benchmark. `bench_agent.py` is the measured coding-bench driver, but its original prompt and tool definitions were private; use `--prompts benchmarks/prompts.example.json` for a new, clearly separate workload. `probe_equal_length.py` is the equal-length stream probe; it requires an explicit `--server-guard-file` that exists only after the server is free for measurement. No included prompt recreates the private headline workload. Only privacy-reviewed aggregate tables are published under `results/`. The benchmark method and the difference between step time and tok/s are in [BENCHMARKS.md](../docs/BENCHMARKS.md). When publishing a result, include prompt shape, cache state, acceptance, image digest and repetition count.
